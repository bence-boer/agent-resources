# Interactive Mode Commands

Commands available during an interactive Gemini CLI session.

## Core Commands

- **`/help`**: Display help information.
- **`/bug`**: Report a bug or provide feedback.
- **`/reset`**: Reset the current session context.
- **`/skills list`**: List available skills.
- **`/skills reload`**: Reload skills.
- **`/mcp list`**: List MCP servers.
- **`/mcp enable <name>`**: Enable an MCP server.
- **`/mcp disable <name>`**: Disable an MCP server.
- **`/quit` or `exit`**: End the current session.

## Key Features

- **Project Awareness**: Automatically analyze your codebase to provide context-aware assistance.
- **Sub-Agents**: Delegate specialized tasks to expert sub-agents (e.g., `codebase_investigator`, `cli_help`).
- **Agent Skills**: Activate specialized skills (like `skill-creator`) to extend the agent's capabilities.
- **Tool Integration**: Access tools for searching, reading, and modifying files, as well as running shell commands.
