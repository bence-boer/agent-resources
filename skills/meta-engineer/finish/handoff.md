# Finish - Handoff

## Use when

The work needs review notes, rollout notes, follow-up context, or a clear extension starting point.

## Route next

- [self-review.md](self-review.md) if the handoff reveals a weak point you still need to tighten

## Apply

- Record the invariant, boundary, or rollout fact the next engineer must not rediscover.
- Record the chosen tradeoff and why it beat the alternatives.
- Point to the tests, logs, or scripts that provide confidence.
- Name the next safe extension point.
- State any remaining follow-up explicitly; do not imply it.

## Resolve explicitly

- What would surprise a future engineer here?
- What operational signal should they watch?
- What deliberate debt remains?
- Where should the next person start?
