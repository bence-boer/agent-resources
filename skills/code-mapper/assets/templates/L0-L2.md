# L0-L2 Template

Use this file when the map should include systems, modules, and key symbols. The template below is one simple graph, not a menu of exclusive shapes. It includes several common subgraph patterns inside one map:

- `forest` - multiple roots remain independent before they connect to the rest of the graph
- `diamond` - two roots converge on one shared symbol
- `hourglass` - several inputs meet at one bottleneck and then fan out
- `branching` - one node splits into multiple downstream branches
- `linear` - local stretches continue through a single main path
- `cross-boundary` - one branch reaches an external boundary
