# L0-L1 Template

Use this file when the map should stay at system and module depth. The template below is one simple graph, not a menu of exclusive shapes. It intentionally includes several common subgraph patterns inside one map:

- `forest` - multiple roots stay independent at the top
- `diamond` - two roots converge on one shared node
- `hourglass` - several inputs funnel through one bottleneck and fan out again
- `branching` - one node splits into multiple downstream paths
- `linear` - local stretches of the graph continue as a single sequence
- `cross-boundary` - one branch reaches an external boundary

```yaml
map:
  describes: "single graph at system/module depth with mixed subgraph patterns"
  depth: "L0-L1"
  generated: "YYYY-MM-DD"
  files_covered:
    - "src/ui/login.ts"
    - "src/api/login.ts"
    - "src/import/a.ts"
    - "src/import/b.ts"
    - "src/core/shared-entry.ts"
    - "src/core/normalize.ts"
    - "src/output/x.ts"
    - "src/output/y.ts"
    - "src/billing/submit.ts"

  roots:
    - node: "ui-login-module"
      functionality: "Starts one entry path into the shared workflow."
      file: "src/ui/login.ts"
      invokes:
        - node: "shared-entry-module"
          functionality: "Receives converging entry paths and starts the shared flow."
          file: "src/core/shared-entry.ts"
          invokes:
            - node: "normalize-module"
              functionality: "Acts as the shared bottleneck before downstream fan-out."
              file: "src/core/normalize.ts"
              invokes:
                - node: "output-x-module"
                  functionality: "Handles one downstream branch after normalization."
                  file: "src/output/x.ts"
                - node: "output-y-module"
                  functionality: "Handles another downstream branch after normalization."
                  file: "src/output/y.ts"
                - node: "billing-submit-module"
                  functionality: "Submits one branch to an external system."
                  file: "src/billing/submit.ts"
                  invokes:
                    - node: "external-billing-gateway"
                      functionality: "Processes the request outside the mapped boundary."
                      boundary: true

    - node: "api-login-module"
      functionality: "Starts a second entry path that converges on the shared workflow."
      file: "src/api/login.ts"
      invokes:
        - reference: "shared-entry-module"

    - node: "source-a-module"
      functionality: "Starts one independent ingest path into the shared bottleneck."
      file: "src/import/a.ts"
      invokes:
        - reference: "normalize-module"

    - node: "source-b-module"
      functionality: "Starts another independent ingest path into the shared bottleneck."
      file: "src/import/b.ts"
      invokes:
        - reference: "normalize-module"
```
