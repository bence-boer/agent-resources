# Finish - Self review

## Use when

Use after implementation and verification, before declaring the task complete.

## Route next

- [foundation-quality-gates.md](foundation-quality-gates.md) - if you still need to tighten the universal finish line
- [finish-handoff.md](finish-handoff.md) - if another person or agent now needs to review or continue the work

## Questions

- If you were reviewing this cold, what would worry you first? Examples: hidden assumption, missing test, awkward coupling
- What part still feels hand-wavy or lucky instead of engineered? Examples: timing, ordering, fallback, docs gap
- What evidence makes you comfortable shipping this now? Examples: reproducible test, clean diff, verified behavior
- What single improvement would most strengthen this change before you stop? Examples: clearer abstraction, regression check, better recovery
