# Foundation - Core framing

## Use when

Use for every task before choosing a solution or touching code.

## Route next

- [foundation-scope.md](foundation-scope.md) - if the request or boundaries are fuzzy
- [foundation-constraints.md](foundation-constraints.md) - if risk, environment, scale, or operating limits matter

## Questions

- What problem are you actually solving, not just what action were you asked to perform? Examples: unblock release, remove friction, stop data loss
- What part of the system or workflow becomes better if this succeeds? Examples: faster decision, safer state, clearer recovery
- What are the few facts you must verify before deciding anything? Examples: current behavior, real constraints, existing patterns
- What would make this change obviously wrong even if it technically works? Examples: user confusion, hidden coupling, harder maintenance
