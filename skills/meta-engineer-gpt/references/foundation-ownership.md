# Foundation - Ownership

## Use when

Use for every task that affects real users, operators, or future maintainers.

## Route next

- [domain-user-value.md](domain-user-value.md) - if the task changes user-visible behavior or perceived quality
- [domain-maintainability.md](domain-maintainability.md) - if the task affects code shape, structure, or future edits
- [finish-self-review.md](finish-self-review.md) - when you need to test your own conviction before stopping

## Questions

- If this ships and breaks, what outcome would you be least willing to defend? Examples: silent failure, lost work, confusing state
- What would make you proud to own this change six months from now? Examples: easy extension, obvious intent, calm operations
- Where are you tempted to stop early, and what unfinished edge would that leave behind? Examples: only happy path, one instance fixed, no rollback story
- Who inherits this after you, and what do they need from you now? Examples: clean structure, explicit constraints, trustworthy verification
