## Questions

- What should the user feel at each step of this flow? Examples: confident, guided, unblocked
- Where can the user hesitate, misread, or lose work? Examples: ambiguous button, hidden status, destructive default
- How should this fit existing flows, language, and expectations? Examples: same navigation, same feedback, same recovery
- What makes the flow feel polished rather than merely possible? Examples: instant feedback, useful empty state, graceful errors
