# Troubleshooting & Resources

## FAQ
- **429 Errors:** Quota exceeded. Check billing or wait.
- **`chmod +x`:** Ensure scripts are executable on Linux/Mac.

## Common Issues
- **Connection:** Check VPN/Firewall if API fails.
- **Auth:** Run `gcloud auth login` or check `GEMINI_API_KEY`.

## Uninstall
- Remove npm package: `npm uninstall -g @google/gemini-cli` (or specific package name).
- Remove config: `rm -rf ~/.gemini`
