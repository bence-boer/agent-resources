# Enterprise Features

Advanced capabilities for organizations.

## Key Features
- **Centralized Configuration:** Manage settings/policies across users/machines.
- **RBAC:** Role-Based Access Control for commands, tools, data.
- **Audit Logging:** Compliance and security tracking.
- **Private Models:** Connect to internal model endpoints.
- **Advanced Security:** HSMs, secure enclaves, MFA.

## Use Cases
- Secure development workflows.
- Automated operations.
- Data governance/compliance.
