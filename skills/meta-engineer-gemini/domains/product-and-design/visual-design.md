# Visual Design

When implementing or modifying UI components, layout, or styling, you must ask yourself:

- Does the aesthetic of this new feature perfectly match or elevate the existing design system? (e.g., consistent spacing, unified color palette, correct typography)
- Is the visual hierarchy immediately obvious, effortlessly guiding the user's eye to the most critical actions? (e.g., prominent primary buttons, de-emphasized secondary actions, effective use of whitespace)
- How does this look, feel, and function across different environments? (e.g., mobile responsiveness, dark mode compatibility, high contrast requirements)
- Are the visual primitives I'm using natively supported and accessible, or am I building a brittle custom implementation? (e.g., native select vs custom dropdown, semantic HTML tags, ARIA attributes)
