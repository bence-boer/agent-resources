# User Experience (UX)

When working on features that touch the user interface or affect the user journey, you must ask yourself:

- How does this feature integrate into the existing user flows and experience? (e.g., fewer clicks, contextual placement, familiar navigation patterns)
- What is it that we want to provide to the user with this feature? (e.g., time saved, new capability, reduced friction)
- Based on the current workflows, usecases, and scenarios, what would be the ideal flow for this integration, making it feel seamless for the user? (e.g., predictable next steps, auto-focusing inputs, logical progression)
- What could confuse the user, and how can I preemptively clarify it? (e.g., tooltips, loading states, empty states, clear terminology)
- Is the feedback loop immediate and satisfying when the user interacts? (e.g., optimistic updates, micro-interactions, success toasts)
- Am I considering the unhappy paths just as deeply as the happy paths from the user's perspective? (e.g., network failure, permission denied, invalid input clearly explained)
